# Pinecœne Curated Studio V1 — Implementation Specification v0.1

**Status:** Implemented candidate on `codex/curated-studio-v1`  
**Audience:** Partners and internal team evaluating the complete medium  
**Standing:** Public, sanitized, `noindex` curated demonstration  
**Governing product law:** **Studio → Genesis → Becoming → Fold / Şekli → Expression → Offering → Locket → Encounter → Return → Successor**

## 1. Product hierarchy

The Studio and executable Fold are the product. The Locket is a downstream permission vessel. It creates an overture, carries an exact Offering package, and opens into only the recipient resolution that the owner granted. The Fold is never manufactured by the Locket and the Locket never possesses owner authority.

The Curated Studio V1 proves four things:

1. An admitted record can deterministically earn a form.
2. Owner decisions change the form under explicit semantic law.
3. Two records produce materially different Pinecœnes.
4. One local Offering and Return circuit can be completed without claiming real delivery, receipt, acceptance, release, Seal, custody, or synchronization.

## 5. Semantic-to-topology law

- admitted commitments strengthen the committed-gold Solid Core;
- Return events emit evidence-blue particulate at deterministic event loci;
- acknowledged Muses create peripheral Constellation topology;
- boundaries create neutral Edges, Bag capacity or phase membranes;
- OPEN events and relations preserve missing faces, gaps and unresolved paths;
- Address changes whole-form orientation but not semantic or topology hash;
- Expression changes finish, tempo and dedication but not topology;
- rejected, removed and unreviewed candidate information is excluded from recipient geometry, motion, sound and serialized packages;
- closure is always explicit and remains `open` for both showcase specimens.

Only seeded PRNG is used for semantic scene placement. `Math.random()` is prohibited. Identical admitted input produces identical semantic, topology, scene and transition hashes.

## 6. Replay and rendering

The owner renderer is a Lit custom element backed directly by Three.js. It consumes only the renderer-neutral scene description. The Becoming has an 84-second causal score, pause, scrub, phase jumps and a 30-second condensed recital. Reduced motion replaces continuous replay with seven explicit phase steps.

The archival Locket remains a separate Lit / Three renderer for closed transport and opening. The Vital Sign is a third Lit / Three renderer with its own authority boundary. It shares deterministic runtime craft but consumes curated Presence controls, never the Fold score.

If WebGL initialization fails, the owner renderer shows the same semantic feature anatomy as a lawful text fallback rather than hiding the product behind a 3D requirement.

## 7. Local custody and truth labels

IndexedDB `pinecoene-showcase-v0` is upgraded additively from version 1 to version 2. Version 1 `pinecoenes` and `returns` stores remain intact. New stores hold studies, Offering v2 packages, Return candidates, dispositions and successors.

Legacy maker data is labelled “Showcase legacy — read-only” and can be exported. It is not promoted into Curated Studio schemas.

All local state changes are labelled simulations. Interface copy does not claim sent, delivered, received, revoked, accepted, released, sealed, synchronized or observed human acts.

## 8. Deliberately deferred

Accounts, cloud database custody, arbitrary uploads, live source reader, live AI, real transport, enforceable revocation, cross-device Returns, successor publication and live Œdit synchronization are not implemented in this release.

## 9. Acceptance evidence

Golden fixture tests freeze semantic, topology, scene and transition vectors for both canonical forms. Invariance tests cover rejected candidates, Expression, timestamps, Address and OPEN closure. Disclosure tests cover ungranted record, scene and transition projection. End-to-end acceptance must cover the complete local circuit and Chromium, desktop WebKit, mobile WebKit, keyboard, reduced motion, sound off, no-WebGL fallback, zoom and 390 × 844 layouts before production promotion.
