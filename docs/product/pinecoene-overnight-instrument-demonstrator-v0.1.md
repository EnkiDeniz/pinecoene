## Implemented demonstration profile

The internal route `/demo` now presents one synthetic object through eight executable operations:

`Projection → Candidate → Fold → Expression → Aperture → Encounter → Return → Passport`

The same normal form can be rendered as a quiet instrument or a Christmas Tree Expression. A wide recipient package and a narrow recipient package are compiled before either is rendered. The Locket remains a separate vessel: its closed state carries no recipient projection bytes, and explicit opening acquires the exact package through the same-origin `/api/demo/offerings/[packageId]` endpoint. Unknown package identifiers fail with `404` and never select a fallback fixture.

The Return operation creates a new immutable local object. The synthetic Successor operation creates a new fixture-authored identity while retaining the predecessor hash unchanged. The final Passport operation proves that the same generic Player can render the Papillœn 7-point, 12-edge graph as data-only calibration without importing Papillœn's product authority or semantics.
